UPDATE FORM

Edition batch des formulaires apprenants a partir du code. Les valeurs sont appliquees explicitement dans l'ordre des codes saisis. Aucune generation aleatoire n'est utilisee.

Retour dashboard Retour general

Mode d'emploi

Une valeur unique s'applique a tous les codes. Une liste entre crochets doit suivre le meme ordre que les codes saisis.

  • Codes accepts: [APP100, APP101], APP100, ou APP100|CLA001.
  • Notes: 4 pour tous, ou [4,5] pour appliquer une note par code dans l'ordre.
  • Commentaires et recommandations: texte simple ou liste ordonnee comme [RAS, Besoin de suivi].
